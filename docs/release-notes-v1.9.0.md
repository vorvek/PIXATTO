# PIXATTO 1.9.0 — The GUI Update

PIXATTO 1.9.0 gives the application a complete interface refresh focused on clarity, character, and everyday usability.

## Changes

- Introduced a polished dark theme with orange accents based on the PIXATTO icon.
- Rebuilt the sidebar as wider, individually bordered blocks so labels and controls no longer feel cramped.
- Added smoothly animated accordion behavior for the Pixelize, Dithering, and Adjustments sections while keeping Presets always available.
- Moved control labels and values above full-width sliders and selectors for better readability.
- Increased the interface text size and bundled Atkinson Hyperlegible Regular and Bold.
- Restyled the Help, Language, and About dialogs to match the new interface.
- Made the language selector fit its contents without a scrollbar or resize corner.
